# gamestudio-tools

Small, custom, CPU-only workflow bumps for the game studio project, built from the
"Game studio workflow tools" catalogue Page. Each tool is one Python file with a README
(usage plus source/licence attribution). Dependencies: Python 3.10+, Pillow, numpy, and pytest for tests (fonttools and ffmpeg are optional).

## One entry point: `gst`

```bash
./gst list                       # all tools with a one-line purpose
./gst list --category maps       # one category
./gst search atlas               # search names, categories and descriptions
./gst atlas-pack sprites/ -o atlas   # run any tool: gst <tool> <its normal arguments>
./gst help lut-tool              # a tool's own --help
./gst doctor                     # check Python, Pillow, numpy, fonttools, ffmpeg, pytest
./gst test                       # run the test-suite
./gst bundle -o release-bundles  # reproducible .tar.gz + .sha256 to copy to another machine
./gst docs -o ~/gamestudio-tools-site   # static HTML docs (searchable, dark theme, no CDN)
./gst fuzz --fast                    # robustness: fuzz reader tools (no traceback; exit 1 or 2)
eval "$(./gst completion bash)"   # tab completion
```

See [docs/pipelines/](docs/pipelines/) for documented end-to-end chains, and [CHANGELOG.md](CHANGELOG.md) for releases. Exit codes: 0 success, 1 issues / CI fail, 2 usage error (passed through from the tool).

Exit codes pass straight through from the tools, so `gst asset-lint ...` works in CI.

## Installing on another machine (not done anywhere yet)

`install.sh` copies the kit to a prefix, optionally creates a venv, and optionally writes a `gst` launcher into a directory you name. It never touches PATH unless you pass `--link-dir`, never installs system packages, and refuses to overwrite a directory or launcher it did not create. Try `--dry-run` first.

```bash
./install.sh --dry-run --prefix ~/gamestudio-tools --link-dir ~/.local/bin --venv
./install.sh --prefix ~/gamestudio-tools --link-dir ~/.local/bin --venv      # --venv pip-installs Pillow and numpy (needs PyPI access); add --with-tests to get pytest in the venv too
./install.sh --tarball gamestudio-tools-2.4.0.tar.gz --prefix ~/gamestudio-tools   # verifies the .sha256 next to it
./install.sh --uninstall --prefix ~/gamestudio-tools --link-dir ~/.local/bin
```

## Known gaps (stated in each README)

- godot-import-presets, godot-tileset and atlas-to-godot: loaded in official Godot 4.7.2.stable.official.ed1daf0bf (`GST_VERIFY_OK`), including TileSet physics polygons, terrain sets / peering bits and compact-grid animations, and unpacked rotated SpriteFrames textures. The optional test `tests/test_godot_load.py` runs when `GODOT_BIN` points at a Godot 4 editor; the binary is not in the kit tarball. `.import` files are written without `uid` / dest paths (the editor fills those in). `**` globs are path-style (`art/**/*.png` matches files in `art/` too).
- godot-tileset skips Tiled animations whose frames do not form a compact atlas grid; ellipse colliders are a 12-gon; a *level* map collider file will not map cleanly onto a tileset sheet. atlas-to-godot unpacks the common 90° CW packed rotation into a sibling PNG (AtlasTexture has no rotation); other angles are not inferred, and a readable sheet is required.
- wav-loud-apply / wav-batch-meta: LUFS uses the same uncertified ITU-R BS.1770-4 meter.
- zstd-encoded Tiled tile data is decoded natively when `compression.zstd` (Python 3.14+), `pyzstd` or `zstd` is importable, and otherwise by the kit's own pure-Python decoder (`lib/zstd_pure.py`, since 2.1.0). Writing zstd (tmx-encode) still needs one of those modules; on this Python 3.13 box it is refused with a one-line error naming them.
- map-objects-to-godot (2.3.0): staggered and hexagonal maps use the screen-pixel object coordinates Tiled stores (the diamond isometric formula is not applied); `tile_to_screen` matches Tiled's stagger/hex grid (`staggeraxis`, `staggerindex`, `hexsidelength`). Polylines become a `Line2D` plus a `CollisionPolygon2D` in segment mode. External `.tsx` / image-collection tilesets and animated tiles (2.2.0) are unchanged. Per-frame offsets and frames of different sizes are not modelled; tile layers are not touched by this tool. Godot has no dedicated polyline collider.
- nav-to-godot (2.3.0): cut pieces are merged with neighbouring walkable rectangles that share a full edge. Collider rectangles that cover a cell only in part still cut that cell (2.2.0); pieces thinner than `--min-piece` (1 px) are dropped, a cell crossed by more than 64 colliders is blocked whole, and only rectangles are cut. `--block-whole-cells` gives the 2.1.0 behaviour.
- font-to-godot (2.2.0): glyph rectangles are checked against each real page image; a declared scaleW/scaleH that disagrees with the image is reported, not refused.
- ase-json-import (2.3.0): rotated frames are kept in the atlas JSON so `atlas-to-godot` can unpack them. Slices (nine-slice insets and pivot) are written as `<out>.slices.json`, a Godot scene with metadata and `Sprite2D` offset, and a `StyleBoxTexture` `.tres` when a nine-slice `center` is present; slice PNGs are cropped in canvas space. Tag expansion (2.2.0) is unchanged. A slice with several keys uses the first key for the scene node (every key is still in the slices JSON).
- asset-viewer: JS syntax-checked and data round-tripped, not interactively tested in a browser.
- fleet-jobs: writes job specs only; the schema is our own, and a runner on turbo still has to be written and approved.
- godot-import-presets, asset-viewer, atlas-convert (libGDX/Starling): see their READMEs; atlas-convert output matches documented formats but was not loaded into those engines.
- build-report imports sibling tools by relative path; keep the folder layout.
- audio-convert needs the local ffmpeg binary.
- glb-lod: vertex clustering, not a quality simplifier; static meshes only.
- font-check: without fontTools it falls back to a render comparison; Pillow's bundled default font lacks e-acute and CJK, so bmfont-gen `--font default` bakes empty boxes for them (use a real TTF).
- tmx-to-json: external .tsx tilesets stay as references.
- ldtk-to-csv: tile flips and offsets are not carried across.
- terrain-erode: a simple grid model, not a particle eroder. tex-gen: prototype quality only.
- wav-loop-meta: whether an engine honours `smpl` loop points on import was not tested in any engine.
- icon-gen: the size lists are the common ones, not checked against current store rules.
- loc-convert: no plural forms; fuzzy flags are read but not written back.
- tileset-gen: hard-edged tiles only, and its 8-bit neighbour bits differ from autotile-gen's 4-bit mask.
- tile-preview: orthogonal finite maps only; external tilesets and animated tiles are not handled.
- obj-uv-unwrap: projection only (concave meshes can overlap in UV space). team-outline: anti-aliased art needs a larger tolerance.
- sfx-bank: PCM only (no loop flags in the Howler map). asset-rename: reference fixing covers common text formats only, so grep before trusting it.
- lit-preview: a preview, not an engine lighting model. drop-sim: exact figures ignore pity; the simulation covers it. font-subset: needs fontTools; WOFF2 needs brotli; check each font's licence. colorblind-sim: approximate dichromacy for design review, not a medical tool.
- sprite-sheet-optimize: no rotated frames in or out; the result is a plain MaxRects layout, not an optimal bin pack. tileset-from-image: exact duplicates only; encoded tile data is refused. map-diff: layers are matched by name, so a rename shows as remove plus add.
- mesh-pivot-fix: shifts root nodes instead of rewriting vertices; skins and root translation animations can override it (warned). voice-slate: read times are the same crude words-per-second estimate as dialogue-extract.
- wav-batch-meta: not a certified meter (no surround weights, PCM integer WAV only); files under 400 ms are measured as one block and flagged SHORT. input-map-lint: Godot parsing is best effort and the code scan is a regex over string literals.
- alpha-bleed: fixes RGB under fully transparent pixels only, not halos baked into semi-transparent edges. sprite-shadow: pixel-art style is a taste call (use --blur 0 for hard shadows). onion-skin: the change ratio is a rough pixel count, not motion analysis.
- map-reach: top-down 4-way/8-way movement only (no jump arcs, no one-way tiles, no infinite maps). collider-preview: axis-aligned rectangles only. loc-fit: basic Pillow text layout, so complex scripts need an engine check.
- loop-xfade: needs pre-roll before the loop start; PCM only; other chunks are dropped. sfx-mix: pitch is plain resampling and filters are first-order; it is not a DAW.
- install.sh: tested only into temporary directories (dry-run, install, upgrade, uninstall, tarball). `--venv` was run for real in 2.2.0 (isolated HOME, temp prefix, pip from PyPI: Pillow, numpy; with `--with-tests` also pytest and fonttools; `gst version` and a `gst test` subset then ran from the venv's python). That run needs PyPI, so the suite only repeats it when `GST_TEST_VENV=1` is set; the default test run covers the dry run. Not run: `--venv` together with `--link-dir` on a real machine, or on Python versions other than 3.13 (the version used for official verification).
- tilemap-stats, map-clean, level-budget, map-diff, tile-preview and tile-anim-gif decode base64 zlib/gzip or csv tile data. zstd is decoded (natively when importable, else by the kit's pure-Python decoder). map-clean now packs firstgids and remaps GIDs unless `--keep-firstgids`.
- sprite-outline-gen: `--keep-size` may clip an outer outline that would have grown the canvas.
- frame-timing-check: a 12 fps grid needs at least a 0.5 ms tolerance (default is 1 ms) or some off-grid frames are flagged.
- cue-sheet: class heuristics (folder name, loop, duration, mono) are a starting point, not a DAW taxonomy; LUFS is the same uncertified meter as wav-batch-meta; PCM only.
- gltf-strip: does not quantise or transcode; custom extensions may hold untracked references.
- text-wrap-bake: the default strips markup and replaces placeholders before wrapping; complex scripts need an engine check (same limit as loc-fit).
- spritesheet-gif: a palette preview flattened onto `--bg`, not a lossless archive.
- hitbox-gen: the circle is the AABB centre or the alpha centroid, not a smallest enclosing circle.
- audio-concat: pitch/speed is resample-only; other RIFF chunks are dropped from the output reel.
- wav-split-silence: a silence threshold, not a sentence segmenter or VAD; other RIFF chunks are not copied onto the takes.
- nine-slice: axis-aligned rectangles only.
- font-preview: Pillow metrics, no complex-script shaping; missing glyphs need fontTools plus a real TTF (Pillow's default font draws a tofu that cannot be told from a glyph).
- parallax-preview: layers wrap as repeating strips; the GIF is a palette preview flattened onto `--bg`.
- tile-anim-gif and tile-preview now resolve external `.tsx` / `.tsj` tilesets (and tile-anim-gif accepts a `.tsx` as input); the map GIF is still finite orthogonal only. zstd-encoded tile data is decoded since 2.1.0.
- wav-trim / wav-loud-apply: PCM only; other RIFF chunks are dropped. wav-loud-apply uses the same uncertified meter as wav-batch-meta (short files are un-gated).
- loc-placeholder-lint: ICU plural/select messages are treated as a single named placeholder, not a tree.
- particle-preview: a kinematic burst/stream for review GIFs, not a runtime particle system.
- sprite-angles: nearest-neighbour rotation of pixel art looks jaggy at odd angles (expected).
- material-audit: custom extensions outside the listed KHR texture slots are not walked for hidden URIs.
- room-graph: connections come from object properties, not from overlapping door tiles.
- map-merge / map-stamp: orthogonal maps, same tile size; infinite chunks are flattened; cells outside the target of a stamp are skipped.
- anim-retarget-fps: the new total can differ from the original by at most one tick.
- credits-roll: Pillow metrics, no complex-script shaping.
- obj-weld: GLB welding is not implemented; `mtllib` / `usemtl` / group / smoothing / comment lines are now preserved.
- tmx-objects-csv: import will not create a missing object layer.
- jump-arc: kinematic only (no coyote time, variable jump, one-way platforms or air control).
- texture-resize: no mip-chain or KTX/Basis output.
- tmx-layer-export: finite orthogonal maps only, same limits as tile-preview.
- wav-chan-split: PCM only; channel labels are conventional, not read from a WAVEFORMATEXTENSIBLE mask; other RIFF chunks are dropped.
- dialogue-to-yarn / dialogue-to-ink: the rebuild is a straight line/choice dump and does not reconstruct conditionals, jumps, or inline expressions that dialogue-extract stripped.
- tileset-wang: one colour, no probability weights; Tiled was not opened to verify painting.
- glb-rename-nodes: custom extras and extension objects are not walked for names.
- sheet-pad: rotated frames are refused; `--keep-layout` inflates unique x/y ranks, which may not stay a regular grid for an irregular pack.
- sfx-envelope: a sample-accurate gain curve, not a DAW filter or compressor; PCM only.
- map-reorder: layers are matched by name (duplicates move together); missing names are reported but are not an error.
- gif-optimize: review-size pass (flattened onto black, full palettised frames), not gifsicle or a lossless archive.
- map-crop: finite maps are clamped to the original bounds; image layers are shifted, not cropped.
- sprite-flip-sheet: rotated frames are refused; trimmed `spriteSourceSize` is not mirrored.
- tmx-props-lint: object properties only (no layer-level rules).
- contact-sheet: Pillow's default font for captions; animated images contribute only the first frame.
- curve-trace: orthographic 2D preview (Y up on the page); the GIF token does not auto-rotate to the tangent.
- godot-tileset: Tiled animations that are not a compact atlas grid are skipped; ellipse colliders are a 12-gon; `--colliders` is tileset-sheet space, not a level map.
- wav-gap-squeeze: peak-threshold gap squeeze, not a VAD; PCM only; other RIFF chunks are dropped.

## Run the tests

```bash
./run_tests.sh        # or: python3 -m pytest -q tests
GODOT_BIN=/path/to/Godot_v4.7.2-stable_linux.x86_64 ./run_tests.sh   # also run the optional Godot load test
```

`samples/` holds smoke-test inputs and outputs (regenerable). `contact_sheet.png` is a visual check.
The optional tests `tests/test_godot_load.py` and `tests/test_showcase_godot.py`
are skipped (the Godot halves) unless `GODOT_BIN` is set to a Godot 4 editor binary.
`examples/showcase-godot/` is a minimal top-down Godot 4.7 scene whose textures,
map, SpriteFrames, step SFX and BMFont are all produced by kit generators; run
`examples/showcase-godot/build_showcase.sh` to rebuild them. When `GODOT_BIN` is
set, that script also imports the project and may write `preview/showcase.gif`.
`examples/sample-game-full/` (2.4.0) is a complete playable 2D action-platformer, *Gem Runner*. It has three Tiled levels (with flipped tiles, object layers, colliders and a navmesh), an Aseprite player and enemy with tagged animations and per-frame hitboxes, a nine-slice UI, a bitmap font, en/de translations, a data-table enemy Resource and looping music. Every asset comes from a `gst` command in its `build.sh`; its README maps each asset to the command that made it. `tests/test_v24.py` rebuilds it reproducibly and, with `GODOT_BIN`, imports it with zero errors and autoplays it to the win screen.
`examples/sample-topdown/` (2.5.0) is a second complete game, *Ember Crypt*, a top-down roguelite. Its two floors come from `dungeon-gen` (seeded BSP) and are autotiled by `map-auto-layer` with a 47-tile blob sheet from `tileset-gen`; the boss arena is built with `map-blank`, `map-fill` and `map-stamp`. It has five enemy kinds (chase, shoot and boss behaviours on a NavigationRegion2D), drop-sim loot tables, save/load linted by `game-data-lint`, en/de/fr text through the `loc-*` and font tools, an input map with keyboard and gamepad on every action (`input-map-lint --parity`), and SFX and music made with the `sfx-*` and `wav-*` tools. `build.sh` uses 86 gst tools (61 not used by the platformer) and its README maps every asset to its command. `tests/test_v25.py` rebuilds it reproducibly and, with `GODOT_BIN`, imports it with zero errors and autoplays a seeded run through the boss in two locales.

2.6.0 keeps the same 262 tools. `sfx-reverse` and the other PCM rearrangements (`wav-invert`, `wav-chan-swap`, `wav-chan-split`, a 0 dB `wav-gain`, an already-mono `wav-mono`, an unscaled `audio-concat`, and a zero-mean `wav-dc-remove`) stay on integer samples, so a same-width copy or reverse is bit-exact. `anim-retarget-fps` reads the name-keyed clips JSON the other animation tools write.
Official verification used 4.7.2.stable.official.ed1daf0bf. The binary is not shipped in the tarball.
